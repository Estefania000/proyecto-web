# Proyecto Web

Proyecto realizado para demostrar el uso de Git y GitHub.

## Objetivo

Organizar el código fuente, controlar los cambios y establecer un flujo de integración para una aplicación web.

## Tecnologías

- HTML
- CSS
- Git
- GitHub
- Visual Studio Code

## Estructura

- `src/`: archivos de la aplicación.
- `tests/`: archivos relacionados con pruebas.
- `.github/workflows/`: configuración de integración continua.
